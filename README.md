# Trustworthy Google Agent Development Kit (ADK) Extensions

ADK Plugins and a support harness for design, development, and deployment of trustworthy agents.

This material supports the talk first presented at [2025 BSides Philadelphia](https://bsidesphilly.org/):
`Your AI Agent Just Got Pwned: A Security Engineer's Guide to Building Trustworthy Autonomous Systems`.

# Usage

## Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/trustworthy-adk.git
cd trustworthy-adk

# Install uv if you haven't already
pip install uv

# Install the package in editable mode
uv pip install -e .
```

## Running Tests

```bash
# Run all tests
uv run pytest

# Run specific test file
uv run pytest tests/test_package.py

# Run with verbose output
uv run pytest -v
```
